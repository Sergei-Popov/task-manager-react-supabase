# Поле `tasks.category` — текст без внешнего ключа

Задача ссылается либо на встроенную категорию (`work`, `personal`, …, живут только
в коде), либо на пользовательскую (uuid из таблицы `categories`). Хранить оба вида
в одном текстовом поле без FK проще, чем заводить таблицу встроенных категорий или
два поля. При удалении пользовательской категории задачи остаются и показываются
с первой встроенной категорией: так решил `getCategoryInfo` на фронтенде.
