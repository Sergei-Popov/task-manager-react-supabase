# Интерфейс на shadcn/ui в стандартной neutral-теме, строгий стиль

После переезда на shadcn/ui пользователь отверг фирменную фиолетовую палитру и
цветные полоски на карточках: «давай придерживаться строгого стиля». Решили: только
стоковая тема shadcn (neutral), тёмная по умолчанию, никаких градиентов, свечений и
цветных рамок. Цвет задачи и тегов допустим только в виде маленькой точки или Badge.
Эмодзи остаются лишь как иконки пользовательских категорий, потому что это данные
пользователя; всё остальное — Lucide.
