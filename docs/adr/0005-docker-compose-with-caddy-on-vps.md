# Деплой: Docker Compose (Postgres + API + Caddy) на VPS

Пользователь выбрал свой сервер вместо Vercel/Neon. Один `docker-compose.yml`
поднимает `db`, `api` и `web`; Caddy отдаёт собранный SPA, проксирует `/api` на
`api:3000` и сам получает HTTPS-сертификат, если задан домен в `SITE_ADDRESS`.
Миграции применяет сам API при старте, отдельного шага деплоя нет.

## Consequences

- Один и тот же compose используется локально (только `db`) и на сервере (все три).
- Внутри Docker API слушает 3000, локально в dev — 3001 (на машине разработчика
  3000 занят).
