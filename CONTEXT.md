# Мои задачи

Персональный менеджер задач: один пользователь видит и меняет только свои задачи,
категории и теги. Один контекст, одна база.

## Язык

### Пользователь и доступ

**Пользователь** (User):
Аккаунт с email и паролем, владелец всех своих задач, категорий и тегов.
_Avoid_: аккаунт, профиль, юзер

**Сессия** (Session):
Факт входа пользователя: случайный токен в httpOnly-cookie, живёт 30 дней.
_Avoid_: токен доступа, JWT, логин-сессия

### Задачи

**Задача** (Task):
Единица работы с текстом и обязательным сроком; принадлежит одному пользователю.
_Avoid_: таск, дело, тикет, карточка (карточка — это способ показа задачи)

**Срок** (Deadline):
Дата и время, к которому задача должна быть выполнена. Всегда с часовым поясом.
_Avoid_: дедлайн, дата задачи, due date

**Статус** (Status):
Этап задачи: `К выполнению` (todo), `В работе` (in_progress), `Завершено` (done).
_Avoid_: состояние, стадия, колонка (колонка — это статус в канбане)

**Приоритет** (Priority):
Важность задачи: `Низкий`, `Средний`, `Высокий`. По умолчанию средний.
_Avoid_: важность, срочность (срочность — это близость срока)

**Просроченная задача** (Overdue task):
Незавершённая задача, срок которой уже прошёл.
_Avoid_: опоздавшая, красная

**Подзадача** (Subtask):
Пункт чеклиста внутри задачи с текстом и флагом выполнения; порядок задан позицией.
_Avoid_: чеклист-айтем, шаг, вложенная задача

**Повторение** (Recurrence):
Настройка периодичности задачи: тип (ежедневно/еженедельно/ежемесячно/ежегодно),
интервал и необязательная дата окончания. Хранится как признак задачи;
автоматического создания следующих экземпляров нет.
_Avoid_: рекуррентность, расписание, цикл

**Цвет задачи** (Task color):
Один из десяти предустановленных цветов, показывается маленькой точкой на карточке.
_Avoid_: метка, маркер, полоска

### Организация

**Категория** (Category):
Единственная рубрика задачи. Бывает встроенной (Работа, Личное, Учёба, Здоровье,
Покупки) или пользовательской (создаёт пользователь, с названием и иконкой-эмодзи).
_Avoid_: папка, проект, список, группа

**Встроенная категория** (Built-in category):
Категория, которая есть у всех пользователей и не хранится в базе; её id — слово
(`work`, `personal`, …).
_Avoid_: системная, дефолтная

**Пользовательская категория** (Custom category):
Категория, созданная пользователем; хранится в базе, id — uuid.
_Avoid_: своя, кастомная, моя категория (в интерфейсе допустимо «Мои категории»)

**Тег** (Tag):
Цветная метка, которых у задачи может быть несколько; принадлежит пользователю.
_Avoid_: лейбл, ярлык, хештег

### Экраны

**Дашборд** (Dashboard):
Главный рабочий экран после входа: сайдбар, статистика, быстрое добавление и одно
из представлений задач.
_Avoid_: главная (главная — это лендинг), панель, кабинет

**Представление** (View):
Способ показа задач на дашборде: `Список`, `Канбан`, `Календарь`.
_Avoid_: режим, вкладка, страница

**Группа срока** (Due bucket):
Раздел списка по близости срока: Просрочено, Сегодня, Завтра, На этой неделе,
Позже, Завершено.
_Avoid_: секция, корзина, бакет

**Фильтр** (Filter):
Текущее ограничение списка: по статусу, категории, приоритету, поиску и флагу
«скрыть завершённые».
_Avoid_: отбор, выборка

**Быстрое добавление** (Quick add):
Создание задачи одним текстом из поля над статистикой; срок подставляется
автоматически (сегодня 18:00 или завтра 18:00, если уже поздно).
_Avoid_: инлайн-создание, быстрая задача

**Лендинг** (Landing):
Публичная главная страница для неавторизованных: описание, превью, кнопки входа
и регистрации.
_Avoid_: главная страница приложения, промо
