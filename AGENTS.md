# AGENTS.md

Инструкции для любых ИИ-агентов (Claude Code, Codex, Cursor и других) в этом
репозитории.

1. Основной файл правил: `CLAUDE.md`. Пошаговые правила: `docs/AI-RULES.md`.
2. Глоссарий терминов: `CONTEXT.md`. Решения, которые нельзя нарушать: `docs/adr/`.
3. Документация: `docs/ARCHITECTURE.md`, `docs/API.md`, `docs/DEVELOPMENT.md`,
   `docs/TESTING.md`, `docs/DEPLOYMENT.md`.
4. Навыки в `.agents/skills/` (гриллинг, диагностика багов, доменное моделирование)
   и проектные рабочие процессы в `.claude/skills/`: `feature`, `bugfix`, `verify`, `ship`.

Коротко: сначала интервью до полного понимания, потом код, потом обязательная
визуальная и функциональная проверка в браузере, потом отчёт с перечнем проверок.
