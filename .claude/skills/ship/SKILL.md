# /ship — зафиксировать и выкатить

1. `npm run lint && npm run build` — чистые, иначе стоп.
2. Убедиться, что `/verify` уже прогнан для текущих изменений (спросить себя: есть ли
   отчёт о проверке в этой сессии; если нет — сначала вызвать навык `verify`).
3. Пересобрать production-стек:
   ```bash
   export DOCKER_HOST=unix://$HOME/.colima/default/docker.sock
   docker compose up -d --build
   until curl -sf http://localhost:8080/api/health >/dev/null; do sleep 1; done
   ```
   Открыть http://localhost:8080 в браузере, войти, снять один скриншот дашборда,
   посмотреть его, убедиться, что в консоли нет ошибок.
4. Обновить документацию, если менялись API, архитектура или термины.
5. Удалить временные файлы, `git status` должен показывать только осмысленные
   изменения. Коммит: короткий заголовок на английском, в теле список изменений
   и трейлеры из системного напоминания сессии.
6. Пуш в `origin main` только после явного «да» пользователя (спросить одним
   вопросом). Деплой на VPS: `git pull && docker compose up -d --build` на сервере,
   см. `docs/DEPLOYMENT.md`.
7. Отчёт: хеш коммита, что вошло, что проверено, запушено или нет.
